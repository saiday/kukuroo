Kukuroo is a Web Push gateway that runs entirely on a free Cloudflare Worker. Enrol your phone once, keep your own keys, and anything that can speak HTTP can put four words on your lock screen: a finished build, a fallen server, a price that finally dropped.

You need a Cloudflare account. That's the list.

No server

ntfy and Gotify are good software, and both need a host, a domain, TLS, and a process that stays up. Kukuroo needs none of that: it is a Worker and a KV namespace, deployed once, asleep until something has news. Static requests cost nothing, and the free plan comfortably covers a personal fleet of devices.

No vendor

The VAPID keypair is generated on your machine and lives in your Worker. The payload is encrypted to a key only your device holds (RFC 8291), so the push service relays ciphertext it cannot read. Nobody has a dashboard with your notification history on it, because there is nowhere for one to be.

No app

Since iOS 18.4, Safari renders Declarative Web Push on its own: no App Store, no $99 a year, no service worker to debug. This is a property of the platform, not of Kukuroo; Kukuroo's job is shipping the server half and the enrolment page so you never think about either.

The whole message fits on your screen

// what actually travels, encrypted end to end { "web_push": 8030, "notification": { "title": "Deploy finished", "body": "main to production, 42s", "navigate": "https://push.example.com/deploys", "tag": "deploys" }, "app_badge": 1 }
web_push: 8030 marks the message as declarative. The browser renders it itself; no JavaScript wakes up.
navigate must be absolute, or WebKit silently drops the whole message. Kukuroo rejects it before sending, along with every other mistake that fails without an error.
app_badge moved position between Safari releases and Apple never documented the move. Kukuroo emits it in both positions so you never have to know.

One-time setup, three moves

Deploy the Worker

Copy the template, pick your origin, deploy. The KV namespace provisions itself; one command generates every secret and keeps the only copy with you.

npm install kukuroo cp -r node_modules/kukuroo/templates/standalone my-kukuroo cd my-kukuroo && npm install npx kukuroo init npx wrangler deploy

Enrol your phone

Open the page, Add to Home Screen, open it from the icon, enter your invite code. Thirty seconds, once per device, and the one manual step Apple will not let anyone script away.

POST when something happens

One bearer token, one HTTP call, from anything: cron, CI, a Raspberry Pi, your backend on AWS. The response tells you exactly how many devices the push service accepted it for.

The fine print, up front

  • iOS 18.4 or later. Declarative Web Push shipped in Safari 18.4, March 2025. On the desktop, macOS Safari works from a normal tab.
  • The Home Screen step is mandatory on iOS. Web push does not exist in a Safari tab. It is a one-time, thirty-second setup, and it is the honest reason this pitch is not "just host a page".
  • Deleting the icon deletes the subscription, silently. If the notifications matter, send yourself a daily ping; the absence of a scheduled message is the only reliable signal the channel died.
  • The free plan has a ceiling. One send reaches up to 50 devices before Cloudflare's subrequest limit, with CPU close behind. For a personal fleet that is comfortable; for a crowd it is not, and the README gives the measured numbers rather than an adjective.
  • It is early. Tested end to end against a real iPhone, and installed so far by exactly one person, who wrote it.

ntfy is excellent if you are happy hosting; go-notify-server got to declarative-first before this project did. Kukuroo exists for the remaining case: you want your own keys and nobody's server, not even yours.

Two things are permanent

1 · The origin

A subscription is bound to the origin it was created on. Change the hostname later and every device goes quiet, with no error anywhere. Decide the address first; the template shuts the doors you are not using.

2 · The VAPID keypair

Regenerate it and every subscription silently stops matching. Kukuroo generates it once, keeps the only copy with you, and refuses to overwrite it, because this is the mistake that cannot be walked back.

The README opens with these before any code, because people hit them before they write any.

Built for

  • Workers you already run and want notifications from, without a notification vendor
  • Anyone who priced an iOS app for one alert and closed the tab

Not for

  • Consumer-scale product notifications
